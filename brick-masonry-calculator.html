HOW IT WORKS

Wall volume minus brick volume

Mortar = Wall Volume − Brick Volume

  • Wall dimensionsEnter length, height and thickness using m, ft or in.
  • Brick dimensionsEnter the actual brick size; the joint thickness is added to each brick dimension.
  • WastageA percentage is added to the calculated brick count for breakage and cutting.

The mortar result is based on geometric volume. Actual site quantities vary with workmanship, brick shape and openings.
