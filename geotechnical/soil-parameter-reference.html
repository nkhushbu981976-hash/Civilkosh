Classification terminology follows the USCS framework referenced by IS 1498. Property ranges are indicative engineering references; the actual design parameters must come from appropriate site investigation and testing.

Standards Basis

IS 1498:1970 provides the soil-classification system and guidance on engineering characteristics. Soil testing is covered by the IS 2720 series. For Nepal projects, the applicable NBC provisions and the project geotechnical report govern design.

The table includes typical ranges rather than code-prescribed design values. Do not select design c′, φ′, γ or permeability solely from this page.

Reference Warning

Site-specific data controls design. Natural variability, groundwater, density, stress history and sampling/testing quality can materially change soil parameters. Obtain and use the project geotechnical investigation, and have foundation decisions reviewed by a qualified geotechnical engineer.
