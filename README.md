# CivilKosh

**Nepal-focused Civil Engineering Tools & Resources**

CivilKosh is a responsive web platform starter for practical civil engineering calculators, converters and reference resources relevant to Nepal.

## Initial toolkit

- Nepal Land Unit Converter
- Concrete Calculator
- Brick Masonry Calculator
- Cement & Sand Calculator
- Civil Unit Converter
- Construction Cost Estimator

## Run locally

Open `index.html` in a browser. No build step or package manager is required.

## Structure

- `index.html` — homepage structure and content
- `styles.css` — responsive visual system
- `app.js` — tool catalog, search and category filtering
