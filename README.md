# CivilKosh

CivilKosh is a lightweight, responsive civic-information website starter for Nepal. The initial version provides a searchable home page, service categories, featured services, and a simple service-detail interaction using plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or package manager is required.

## Structure

- `index.html` — page structure and content
- `styles.css` — responsive visual system
- `app.js` — search, category filtering, and service details
