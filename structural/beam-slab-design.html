Code & assumptions

Primary Nepal basis
NBC 110:1994 Plain and Reinforced Concrete is the Nepal RC code and refers to IS 456:2000. Current DUDBC listings also identify NBC 105:2025 as Nepal's seismic design code and NBC 205:2024 as a ready-to-use low-rise RC detailing guideline. This calculator uses IS 456 flexural provisions for the stated preliminary member check. citeturn4search30turn0search7
  • Only a simply supported, uniformly loaded member is analysed.
  • No seismic/wind action, torsion, concentrated loads, continuous-span redistribution, flanged-beam action or doubly reinforced design is included.
  • The tool does not perform a complete shear, deflection, crack-width, anchorage or ductile-detailing design.
  • For slabs, the flexural calculation represents a 1 m one-way strip; two-way action is outside this module.
Engineering warning. This is a preliminary calculation aid, not a final structural design. A qualified structural engineer must verify the analysis model, loads, load combinations, detailing, seismic requirements and governing local approvals before construction.
